# جدارية التسامح الإلكترونية

تطبيق ويب عربي (RTL) لجمعية الرعاية الإسلامية — نموذج لإرسال رسائل التسامح وجدارية بطاقات تفاعلية مع حفظ في `localStorage`.

## التشغيل المحلي

```bash
cd Tolerance-Wall
python3 -m http.server 5173 --bind 127.0.0.1
```

ثم افتح: http://127.0.0.1:5173/

## الملفات

- `index.html` — الهيكل والواجهة
- `styles.css` — الهوية البصرية (بنفسجي دافئ، تركواز، أخضر عشبي)
- `app.js` — النموذج، التبديل، والجدارية مع `localStorage`
- `assets/islamic-care-logo.png` — شعار الجمعية
